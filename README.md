# 📈 SentimentPulse: Analizador de Sentimiento en Tiempo Real

Proyecto desarrollado en Python para extraer, filtrar y analizar el sentimiento de noticias globales utilizando procesamiento de lenguaje natural (NLP).

# Funcionalidades
* Extracción de Datos: Conexión con NewsAPI para obtener titulares actuales.
* Análisis NLP: Clasificación de polaridad (sentimiento) con la librería `TextBlob`.
* Filtros Dinámicos:** Capacidad de segmentar noticias por umbrales de positividad/negatividad.
* Seguridad: Manejo de credenciales mediante variables de entorno (`.env`).

#Tecnologías Usadas
* Lenguaje: Python 3.10+
* Análisis de Datos: Pandas
* **NLP:** TextBlob
* Gestión de API: Requests & Dotenv
* Control de Versiones: Git & GitHub
